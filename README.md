# MovieVerse

## Assignment #3 – Media Queries + Bootstrap Grid

MovieVerse is a simple movie website created for Assignment #3.

The project uses CSS Media Queries and Bootstrap 5 to make the website responsive on mobile, tablet, and desktop screens.

## Project Pages

- `index.html` – Main page with movies and Bootstrap carousel
- `movie.html` – Movie information page
- `favorites.html` – Favorite movies
- `profile.html` – User profile and form

## Main Features

### Responsive Design

The website uses CSS Media Queries.

- Desktop: 3 cards in one row
- Tablet: 2 cards in one row
- Mobile: cards are displayed vertically

Font sizes also change for different screen sizes.

### Bootstrap Grid

Bootstrap Grid is used for the main layouts.

The project uses classes such as:

- `container`
- `row`
- `col-md`
- `col-lg-6`
- `col-lg-4`

### Bootstrap Navbar

The website has a responsive Bootstrap navigation bar.

It contains links to the main pages and changes to a hamburger menu on smaller screens.

### Bootstrap Buttons

Bootstrap buttons are used for actions on the website.

The project uses classes such as:

- `btn`
- `btn-primary`
- `btn-secondary`
- `btn-outline`
- `btn-sm`

### Bootstrap Carousel

The main page contains a Bootstrap carousel with 9 images.

The carousel has navigation indicators and previous/next controls.

### Bootstrap Cards

Bootstrap cards are used to display movie information.

Each card contains an image, title, and description.

### Responsive Form

The profile page contains a responsive form using Bootstrap classes such as:

- `form-control`
- `form-label`
- `form-select`

## Responsive Design

The website was tested on different screen sizes.

The layout changes automatically depending on the screen width.
