# MovieVerse - Assignment #2

Advanced CSS assignment using Flexbox and CSS Grid.

## Implemented requirements

- Flexbox navigation bar with logo, links, spacing and vertical alignment.
- Flexbox card rows with equal-height cards, gaps and hover effects.
- CSS Grid page layout with header, sidebar, main content and footer using grid areas.
- CSS Grid movie gallery with 9 images, equal columns/rows, gaps and hover captions.
- Responsive layout for desktop, tablet and mobile screen sizes.
